## 结论

MiaoTarot 的爆点不该是“猫塔罗”“选一张牌”或一句正经毒鸡汤。这些都容易被替换。更有机会形成自有格式的是：

```text
当日共同语境里的怪问题
→ 观众产生“塔罗怎么回答这个”的开放回路
→ 真实发疯模式和抽牌证明产品存在
→ 真牌义与荒诞回答形成第二次意外
→ 评论区提供下一集问题
```

这让营销内容同时完成四件事：借势、喜剧、产品演示、连续选题。第一条已经用 `#全宇宙最阴的物件` 做成 18 秒有声发布版。

## 用户为什么会停

### 1. 认知失谐

塔罗通常被用来问感情、事业和未来；`生姜伪装成土豆到底图什么` 把一个郑重的解释系统用在极不郑重的问题上。笑点先来自用途错配。

### 2. 开放回路

第一个奖励不是答案，而是问题本身。观众会自然想知道：一张正经塔罗牌如何处理这个荒谬提问。答案必须是第二个奖励，不能把问题换一种说法。

### 3. 共同生活经验

“咬到伪装成土豆的生姜”“冷热水龙头只有烫熟和冷藏”都不需要复杂背景。热梗提供的是命名和当下感，真实生活经验提供更长的寿命。

### 4. 参与式补完

`你家最阴的物件是什么？` 不是空泛求评论。观众天然有透明胶带、卡纸打印机、叠塑料凳等候选，评论直接变成下一集题库，也让用户对系列产生一点共同创作感。

### 5. 笑完后的可信恢复

荒诞回答后立即显示 `月亮＝幻象 / 不确定 / 别把第一眼当事实`。这告诉用户 MiaoTarot 不是随机骂人：风格可以疯，牌义不能乱。

### 借梗规则

- 借的是 `情绪结构 + 句式模板 + 当下共同语境`，不是下载热门图片换 Logo。
- 每个梗记录 `observedAt`、来源、预计 TTL、视觉权利和 Miao 对应牌义。
- 当“品牌都在套”且观众无需 Miao 也能得到同样笑点时，立即停用。
- 画面必须原创；问题与答案至少有一处只属于猫塔罗。

## 可持续问题公式

高打开率问题通常不是随机胡言乱语，而是：

```text
一个人人见过的东西
+ 把它拟人化成有明确动机
+ 让小麻烦升级成荒诞阴谋
+ 留出一张塔罗牌能接住的语义
```

模板：

- `X 每次在 Y 的时候出现，它到底图什么？`
- `我是在做 A，还是在参加 B？`
- `X 是不是闻到我着急，才开始 Y？`
- `要不要做 A，还是先用荒谬方式 B？`
- `从心理学 / 科学角度，为什么一到 X，Y 就像 Z？`

## 语气模式怎么设计

当前产品只保留两个顶层模式是对的：

| 模式 | 用户需求 | 语言规则 |
| --- | --- | --- |
| 正常模式 | 想被理解、把牌义说清楚 | 温和、具体、不给命运结论 |
| 发疯模式 | 想被逗笑、想截图和转发 | 高反差、短句、物件拟人化；不羞辱用户；牌义不变 |

闺蜜、哥们、尖酸、心理学、科学型并不都属于同一维度：

- `闺蜜 / 哥们 / 尖酸` 是关系语气。
- `心理观察 / 科学解释` 是解释镜头。
- `正常 / 发疯` 是表达强度。

若全部做成并列按钮，移动端会产生选择负担，且当前模式选择本来就在问题区下方。先把它们做成后台 style cards 和内容栏目；只有某一种连续带来更高完成、分享和回访，才升级为用户可见选项。

### 推荐架构

现在不需要向量数据库。78 张牌、2 个模式和几十条批准示例是小而稳定的结构化知识，直接 JSON / TypeScript 约束会更准确：

```text
用户问题
→ 安全分类与是否降级正常模式
→ 现有牌义真相层
→ voice mode style card
→ 取 2–4 条同主题批准示例
→ 生成
→ 检查是否改牌义、羞辱用户或做高风险断言
```

建议建立三个小库，而不是一个“大而杂的 RAG”：

1. `card_truth`：项目现有 78 张牌义、正逆位、允许的观察角度。
2. `style_cards`：正常 / 发疯，以及内部试验的闺蜜、哥们、心理观察、科学解释规则。
3. `approved_examples`：人工通过的问题—牌—回答三元组，带主题、笑点机制、安全标签和效果数据。

只有当批准示例达到约 500–1000 条、需要按主题和用户语境检索时，再给 `approved_examples` 加 embedding。实时热梗不进长期向量库，而进带 TTL 的 `trend_hooks`，过期自动退出候选。

## 平台方法

- TikTok 官方仍建议 `Hook → Body → Close`，并强调前几秒和产品露出；Miao 的翻译是“怪问题 → 真实模式与牌 → 评论续题”。
- YouTube Shorts 不只看播放量，要看 `How many chose to view`、留存、重播和 remix；后段 spike 应反推到下一版更早的位置。
- Reels 继续按 9:16、有声、安全区设计；静音也必须看懂。

## 第一轮发布实验

不要同时更换问题、牌、答案、音乐和结尾。第一轮至少发布三条：

1. 生姜 / 月亮。
2. 水龙头 / 节制。
3. 背手猫 / 倒吊人。

保持产品镜头、字号、时长和评论 CTA 一致。晋级标准：

- 首先看选择观看和 1 秒停留，判断问题。
- 再看 3 秒留存，判断产品露出节奏。
- 再看完播、重播和分享，判断答案。
- 最后看有效评论续题与开始抽牌，判断格式是否能形成增长循环。

高播放但低评论、低主页访问，说明只是一次性段子；高点击但低开始抽牌，说明成片承诺和真实入口不一致。
