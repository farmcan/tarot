# MiaoTarot 热梗短视频脚本

## 39 秒产品解释版

**用途：** 爆点后的完整产品证明，不替代 18 秒传播剪辑。

**成片：** 1080×1920、30fps、39.0 秒；Tingting 普通话旁白、原创节奏轨、点击 / 翻牌 / 落点 SFX、常驻字幕。

### 最终旁白

> 生姜每次伪装成土豆接近我，它到底图什么？
>
> 我把问题交给 MiaoTarot，选了发疯模式。
>
> 但它不只有一句段子。
>
> 这里能选经典二十二张大牌，或者涂鸦七十八张全牌；
>
> 一到五张，单牌、双牌、三牌、四牌、选择权衡和关系剖面，六种牌阵都在。
>
> 正位逆位也保留。
>
> 牌由你亲手洗、切、抽，AI 不洗牌，也不换牌。
>
> 翻开后先看牌名、牌位和标准含义，
>
> 再听猫用正常或发疯的方式，把话说清楚。
>
> 还能继续追问，回看最近八次，生成分享图。
>
> 它不替你预测命运，只帮你换个角度看清问题。
>
> 打开 MiaoTarot，把问题交给牌，把选择留给自己。

旁白使用 Tingting 普通话、285 语速，母带长 38.17 秒；第 0 帧开始发声。伴奏只做节奏底，不与中文口播争抢中频。

## 系列

**系列名：** `今天给塔罗问点没用的`

**本集：** `#全宇宙最阴的物件 · 生姜`

**成片：** 1080×1920、30fps、18.0 秒；Tingting 普通话旁白 + 140 BPM 原创轻怪诞节奏轨 + 点击 / 翻牌 / 落点 SFX。

## 最终旁白

> 菜里的生姜，每次伪装成土豆接近我，它到底图什么？
>
> 我让猫用发疯模式审了它。结果抽到月亮牌。
>
> 月亮牌提醒你，别把第一眼当事实。
>
> 它图的不是你，是你毫无防备的那一口。
>
> 你家最阴的物件是什么？评论区报案，下一条让猫审。

旁白使用 Tingting 普通话、250 语速，总长 16.9 秒。问题不等字幕铺完才开口，第 0 帧立刻发声。

节奏轨在 5.82–6.08 秒翻牌前短暂抽空，8.20 秒回答出现时重新落拍；回答段降低伴奏音量，优先保证中文口播可懂。

## 文案约束

- 第一问必须比答案更有打开率；答案负责二次奖励。
- 发疯回答必须从真实牌义长出来，不能把任意段子硬贴在牌上。
- 不辱骂提问者，不把创伤、疾病、贫困、身份或外貌当笑点。
- 心理学型只说观察和可能机制，不诊断；科学型只解释可核验事实，不伪装成科学证明塔罗。
- 热梗只用结构和共同语境，画面、问题和答案必须原创。
